# Lubuntu
My first steps learning Linux and moving away from Windows.

Why I Started Learning Linux

I wanted to try a lighter and more customizable operating system because my old laptop was becoming slow with Windows 7. After hearing about Linux and especially Lubuntu, I decided to start learning and use it as my main operating system.
Goal
Install Linux on my laptop
Learn the basic Linux command line
Understand how Linux works compared to Windows
Use Linux for programming and studying
# Day 1 - Downloading Linux

Today I started by searching for a Linux distribution that works well on older computers. I chose Lubuntu 22.04 LTS because:

It is lightweight
It is easy for beginners
It works well on old laptops
It is based on Ubuntu, so there are many tutorials

I downloaded the ISO file : lubuntu-22.04.4-desktop-amd64.iso
